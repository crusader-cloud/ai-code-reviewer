# 🚀 Quick Start Guide - AI GitHub PR Reviewer

## What You Got

A **single HTML file** (`pr-reviewer-standalone.html`) that runs in your browser - no installation needed!

## How to Use It

### 1️⃣ Open the File
- Go to: `c:\Users\user\Desktop\hack2\`
- **Double-click** `pr-reviewer-standalone.html`
- Opens in your browser automatically

### 2️⃣ Get Your Keys

**GitHub Token:**
- Visit: https://github.com/settings/tokens
- Click "Generate new token (classic)"
- Select: `repo` + `read:user`
- Copy the token

**Anthropic API Key:**
- Visit: https://console.anthropic.com/
- Create an API key
- Copy it

### 3️⃣ Login
- Paste both keys into the form
- Click "🚀 Start Reviewing"
- Done! Your keys are saved in the browser

### 4️⃣ Review PRs
1. **Pick a repository** from your list
2. **Select a pull request**
3. **Click "Analyze Code"**
4. **Review the AI findings**
5. **Post to GitHub** (optional)

### 5️⃣ Manual Review
- Click the **✍️** button (bottom right)
- Paste any code
- Get instant AI review

## ✨ Features

✅ GitHub login with Personal Access Token

✅ Manual code review
